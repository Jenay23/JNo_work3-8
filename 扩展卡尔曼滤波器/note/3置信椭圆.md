# 置信椭圆

## 为什么是椭圆？

二维高斯分布的等高线方程：

\[
(\boldsymbol{x} - \boldsymbol{\mu})^T \Sigma^{-1} (\boldsymbol{x} - \boldsymbol{\mu}) = \text{常数}
\]

分解特征值/特征向量后变为椭圆标准方程：

\[
\frac{(x_1' - \mu_1')^2}{\lambda_1} + \frac{(x_2' - \mu_2')^2}{\lambda_2} = \text{常数}
\]

所以数学上天然是椭圆。

## 参数

由协方差矩阵决定：

| 参数 | 含义 | 来源 |
|---|---|---|
| 椭圆心 \((\mu_x, \mu_y)\) | 均值位置 | 状态估计值 |
| 半长轴 \(a\) | 最大不确定方向的范围 | \(\sqrt{\lambda_{\max}}\) |
| 半短轴 \(b\) | 最小不确定方向的范围 | \(\sqrt{\lambda_{\min}}\) |
| 朝向角 \(\theta\) | 椭圆旋转角度 | 最大特征值对应的特征向量方向 |

- 特征值 = 该方向的**方差**（散布程度）
- 特征向量 = 该方向的**方向**（主方向）

## 不同相关性的形状

| 情况 | 协方差矩阵 | 形状 |
|---|---|---|
| 无相关，σx = σy | diag(σ², σ²) | **正圆** |
| 无相关，σx ≠ σy | diag(σx², σy²) | **正椭圆**（轴平行坐标轴） |
| 正相关 | 有非对角正数 | **椭圆朝右上倾斜** |
| 负相关 | 有非对角负数 | **椭圆朝左上倾斜** |

## 概率含义

| 缩放系数 k | 概率 | 含义 |
|---|---|---|
| 1.00 | 39.35% | 标准协方差椭圆 |
| 2.00 | 86.47% | |
| 2.45 | 95.00% | 常用置信椭圆 |
| 3.00 | 98.89% | |

缩放系数公式：\(k = \sqrt{-2\ln(1-p)}\)

## 矩阵元素在卡尔曼滤波中的对应

### 状态向量 x

```
[x]         一维卡尔曼（标量）
[y]         

[x ]        二维卡尔曼：位置x, 位置y
[y ]     

[x ]        四维卡尔曼：位置x, y, 速度vx, vy
[y ]
[vx]
[vy]
```

每一行是一个**状态变量**。

### 状态转移矩阵 F

```
F = [1  Δt]     匀速运动模型：
    [0  1 ]      x_{n+1} = x_n + Δt·v_n
                 v_{n+1} = v_n
```

- 第一行：如何从旧状态算新位置（旧位置 + 速度×Δt）
- 第二行：如何从旧状态算新速度（不变）
- **本质就是用矩阵乘法一次性预测所有变量**

### 协方差矩阵 P

```
P = [σx²   σxy]    二维例子
    [σyx   σy²]
```

| 元素位置 | 含义 |
|---|---|
| P[0][0] = σx² | x 方向估计的方差（不确定度） |
| P[1][1] = σy² | y 方向估计的方差（不确定度） |
| P[0][1] = P[1][0] = σxy | x 和 y 的协方差（相关性） |

对角线 → 各变量自身的误差大小
非对角线 → 变量之间的相关程度（0 = 无关）

### 测量矩阵 H

```
H = [1 0]    只能测位置x，看不到y和速度
```

把**真实状态**映射到**测量空间**。告诉滤波器：你测到了什么，没测到什么。

### 测量噪声矩阵 R

```
R = [σz²]    一维测量
    或
R = [σzx²  0 ]    二维测量（两个传感器无相关）
    [0   σzy²]
```

测量设备本身的误差大小。

### 过程噪声矩阵 Q

描述系统模型本身的不可靠性（比如匀速模型没考虑加速）。

```
Q = [σv²·Δt⁴/4   σv²·Δt³/2]    示例：匀速模型
    [σv²·Δt³/2   σv²·Δt²  ]
```

### 卡尔曼增益 K

```
K = P·H^T·(H·P·H^T + R)^{-1}
```

**一维时就是除法**：
K = 预测不确定度 / (预测不确定度 + 测量不确定度)

**多维时用逆矩阵实现同样的"权重分配"**：
- K 大 → 更相信测量
- K 小 → 更相信预测

### 核心方程一览（矩阵形式）

| 方程 | 运算 | 作用 |
|---|---|---|
| x_pred = F·x | 矩阵×向量 | 预测下一时刻状态 |
| P_pred = F·P·F^T + Q | 矩阵乘法+加法 | 预测不确定度传播 |
| K = P_pred·H^T·(H·P_pred·H^T + R)^{-1} | 乘法+求逆 | 计算增益 |
| x_upd = x_pred + K·(z - H·x_pred) | 向量运算 | 融合测量值 |
| P_upd = (I - K·H)·P_pred | 矩阵运算 | 更新不确定度 |

**所有一维标量运算，到多维全变成矩阵运算，逻辑完全一样。**

## 如果不相关会怎样

各状态变量之间**完全不相关** → 协方差矩阵 P 的非对角元素全为 0：

```
P = [σx²   0    0    0 ]
    [0   σy²   0    0 ]
    [0    0   σvx²  0 ]
    [0    0    0   σvy²]
```

**后果：**

- 卡尔曼滤波退化为**多个独立的一维滤波器并行运行**，各变量互不影响
- 置信区域不再是歪的椭圆 → **正椭圆或正圆**
- 一个变量的测量更新不会影响另一个变量的估计
- 但现实中这种理想情况很少见，比如位置和速度天然就有相关性（位置 = 速度×Δt）

## n 维置信区域什么样

n 维高斯分布的等高线是一个 **n 维超椭球**。

```
1 维：线段      [---μ---]        长度 = 2σ

2 维：椭圆                      🥚 形状（或正圆）

3 维：椭球                      🏈 橄榄球形状

4 维及以上：超椭球（无法直接可视化）
```

### 数学定义

n 维超椭球方程：

\[
(\boldsymbol{x} - \boldsymbol{\mu})^T \Sigma^{-1} (\boldsymbol{x} - \boldsymbol{\mu}) = k^2
\]

- 有 n 个轴，每个轴的方向 = 特征向量
- 每个轴的半长度 = \(k \cdot \sqrt{\lambda_i}\)（\(\lambda_i\) 是特征值）
- k 由期望概率决定（查卡方分布表）

### 不同维度的概率-缩放系数

n 维时，缩放系数 k 要根据**卡方分布**查表：

| 概率 | 1维 (k) | 2维 (k) | 3维 (k) |
|---|---|---|---|
| 39.35% | 1.00 | 1.00 | 1.00 |
| 50% | 0.67 | 1.18 | 1.54 |
| 90% | 1.64 | 2.15 | 2.50 |
| 95% | 1.96 | 2.45 | 2.80 |
| 99% | 2.58 | 3.03 | 3.37 |

### 可视化方式

- **1 维**：误差条（±σ）
- **2 维**：置信椭圆（直观，常用）
- **3 维**：3D 椭球（可用工具绘制，如 matplotlib）
- **4 维+**：无法直接可视化，通常降维处理：
  - 只看某两个维度的投影椭圆
  - 或者只看各维度的边缘分布（忽略相关性）

## 期望代数：规则 6 和规则 7

### 规则 6：\(E(X \pm Y) = E(X) \pm E(Y)\)

- **条件**：无。X 和 Y 可以是任意两个随机变量。
- **原因**：

\[
E(X \pm Y) = \sum_x \sum_y (x \pm y) p(x,y)
= \sum_x \sum_y x p(x,y) \pm \sum_x \sum_y y p(x,y)
\]

\[
= \sum_x x \sum_y p(x,y) \pm \sum_y y \sum_x p(x,y)
= \sum_x x p(x) \pm \sum_y y p(y)
= E(X) \pm E(Y)
\]

每一步都是求和分配律，不依赖 p(x,y) 的任何形式。**期望是线性算子，加法永远可拆。**

### 规则 7：\(E(XY) = E(X)E(Y)\)

- **条件**：X 和 Y **必须相互独立**。
- **原因**：

\[
E(XY) = \sum_x \sum_y xy \, p(x,y)
\]

要拆成：

\[
E(X)E(Y) = \left( \sum_x x p(x) \right) \left( \sum_y y p(y) \right)
\]

必须满足 \(p(x,y) = p(x)p(y)\)，即**独立**。否则无法把联合概率拆成边缘概率乘积。

### 对比总结

| 规则 | 公式 | 需要独立？ | 原因 |
|---|---|---|---|
| 6 | \(E(X \pm Y) = E(X) \pm E(Y)\) | 不需要 | 期望的线性，求和分配律无条件成立 |
| 7 | \(E(XY) = E(X)E(Y)\) | **必须独立** | 乘法可拆需要联合概率=边缘概率乘积 |

## 协方差的定义

\[
COV(X,Y) = E[(X - \mu_X)(Y - \mu_Y)]
\]

### 为什么要这样定义

把每个样本点的 X 和 Y 分别减去各自的均值，得到**偏离方向**，然后相乘：

| 情况 | \(X - \mu_X\) | \(Y - \mu_Y\) | 乘积 | 协方差符号 |
|---|---|---|---|---|
| 同向偏大 | + | + | + | 正 |
| 同向偏小 | - | - | + | 正 |
| 反向（X大Y小） | + | - | - | 负 |
| 反向（X小Y大） | - | + | - | 负 |
| 无关系 | + / - 随机 | + / - 随机 | 正负相抵 | 接近 0 |

**本质：把所有样本点"X和Y同时偏离均值的程度"取平均。**

- **正** → X 和 Y 同涨同跌（正相关）
- **负** → X 和 Y 此消彼长（负相关）
- **0** → 无线性关系

### 法则 11 是推导结果，不是定义

\[
COV(X,Y) = E(XY) - \mu_X \mu_Y
\]

就是从定义展开算出来的等价形式，方便计算用。**不是"两个方差相乘"**，方差乘积是 \(\sigma_X^2 \sigma_Y^2\)，完全不同。

---

## 法则 15：\(V(XY) \neq V(X)V(Y)\)

假设 X, Y 独立，展开两边：

\[
V(XY) = E[(XY)^2] - [E(XY)]^2
      = E(X^2 Y^2) - [E(X)E(Y)]^2
      = E(X^2)E(Y^2) - [E(X)]^2[E(Y)]^2
\]

\[
V(X)V(Y) = [E(X^2) - (E(X))^2] \cdot [E(Y^2) - (E(Y))^2]
\]

分配律展开：

\[
V(X)V(Y) = E(X^2)E(Y^2) - E(X^2)[E(Y)]^2 - E(Y^2)[E(X)]^2 + [E(X)]^2[E(Y)]^2
\]

对比：

| 项 | V(XY) | V(X)V(Y) |
|---|---|---|
| \(E(X^2)E(Y^2)\) | ✅ | ✅ |
| \(-[E(X)]^2[E(Y)]^2\) | ✅ | ✅ |
| \(-E(X^2)[E(Y)]^2\) | ❌ | ✅ |
| \(-E(Y^2)[E(X)]^2\) | ❌ | ✅ |

V(XY) 比 V(X)V(Y) **少了中间两项**，所以两者不相等。

### 直观理解

- \(V(X)V(Y)\) = X 的散布 × Y 的散布
- \(V(XY)\) = XY 这个**乘积**作为一个新随机变量的散布

乘积的散布不仅取决于各自散布大小，还取决于各自的均值。即使 X 和 Y 都不怎么散布（方差小），只要均值大，乘积的方差也可能很大。反之亦然。所以不能简单等于方差相乘。

## 总体协方差 vs 样本协方差（N 与 N-1）

### 符号说明

- \(\mu_X, \mu_Y\)：全体数据的真实均值（理论值，实际中不知道）
- \(\bar{x}, \bar{y}\)：手头 N 个样本算出来的均值
- \(x_i, y_i\)：第 i 个样本的具体数值
- N：样本个数
- \(E()\)：期望（理论上的平均）
- \(\sum_{i=1}^{N}\)：对 N 个样本求和

### 两个公式不矛盾

**理论公式**（规则 11）：

\[
COV(X,Y) = E[(X - \mu_X)(Y - \mu_Y)]
\]

意思是：把每个点的 X 偏离真实均值的量 乘以 Y 偏离真实均值的量，再取平均。这里用的是**总体真实均值**，分母用 N（因为已知真实均值时不需要校正）。

**样本公式**：

\[
COV(X,Y) = \frac{1}{N-1} \sum_{i=1}^{N} (x_i - \bar{x})(y_i - \bar{y})
\]

因为不知道总体均值 \(\mu_X, \mu_Y\)，所以用样本均值 \(\bar{x}, \bar{y}\) 代替。但由于样本均值是从同一批数据算出来的，会导致偏差偏小，所以分母用 N-1 而不是 N。

| 情况 | 用什么均值 | 分母 | 是否无偏 |
|---|---|---|---|
| 已知总体均值（理论） | 真实均值 \(\mu\) | N | ✅ 无偏 |
| 未知总体均值（实际） | 样本均值 \(\bar{x}\) | N-1 | ✅ 无偏 |
| 未知均值但错误地用 N | 样本均值 \(\bar{x}\) | N | ❌ **有偏（偏小）** |

**不矛盾**，而是理论公式用真实均值，实际计算用样本均值，后者需要 N-1 补偿偏差。

### 为什么样本均值会导致系统性偏低

先说方差（更容易理解），协方差同理。

真实方差公式：

\[
\text{方差} = \frac{1}{N} \sum_{i=1}^{N} (\text{数据点}_i - \text{总体均值})^2
\]

但总体均值不知道，只能用样本均值代替。

**关键性质：** 样本均值是使"偏差平方和"最小的那个数。对任意一组数据，你拿任何一个数 c 来算 \(\sum (x_i - c)^2\)，这个和都是在 \(c = \bar{x}\) 时最小。

数学表达：

\[
\sum_{i=1}^{N} (x_i - \bar{x})^2 \leq \sum_{i=1}^{N} (x_i - c)^2 \quad \text{对所有} \, c
\]

所以用样本均值代替真实均值，偏差平方和**一定小于或等于**用真实均值算的结果。除非样本均值恰好等于真实均值（概率极低）。

### 举例

假设总体真实均值 \(\mu = 0\)，抽 3 个样本：

| 抽到的样本 | 样本均值 \(\bar{x}\) | 用真实均值 0 算：平方和 | 用样本均值算：平方和 |
|---|---|---|---|
| [-1, 0, 1] | 0 | \((-1)^2 + 0^2 + 1^2 = 2\) | 2（这回相等，因为 \(\bar{x}\) 恰好 = 0） |
| [0, 1, 2] | 1 | \(0^2 + 1^2 + 2^2 = 5\) | \((-1)^2 + 0^2 + 1^2 = 2\)（**偏小了！**） |

第二行最典型：样本 [0, 1, 2]，真实均值假设是 0，偏差平方和是 5。但用样本均值 1 来算，偏差变成了 -1, 0, 1，平方和只有 2。**被压缩了 60%**。

如果用 N=3 去除，算出来方差 = 2/3 = 0.67，但真实方差应该是 5/3 = 1.67——严重低估。

**所以需要把分母从 N 换成 N-1，人为把结果拉大一点**，让期望值恰好等于真实方差。

### N-1 是精确算出来的，不是拍脑袋

不是随便选 N-1，而是解出来的：

\[
E\left[ \frac{1}{N-1} \sum_{i=1}^{N} (x_i - \bar{x})^2 \right] = \sigma^2 \quad (\text{真实总体方差})
\]

只有 N-1 能让这个期望成立。换成 N-2 就补过头，换成 N 就补不够。

**自由度解释：** N 个数据点，算均值用掉了 1 个"约束"（\(\sum (x_i - \bar{x}) = 0\)），剩下独立信息的数量是 N-1，所以有效信息量是 N-1 而不是 N。

## 迹（Trace）

迹是矩阵**对角线元素之和**，记作 \(tr(\Sigma)\)：

\[
tr(\Sigma) = \sigma_1^2 + \sigma_2^2 + ... + \sigma_n^2
\]

**几何意义：** 把矩阵看作线性变换时，迹 = 变换前后体积缩放倍数的总和。

**在协方差矩阵中：** 迹 = 各变量方差之和 = 总不确定度。

在卡尔曼滤波中常看迹的变化来判断滤波器整体收敛情况。

## 半正定 vs 正定矩阵

### 定义对比

| | 半正定 (positive semidefinite) | 正定 (positive definite) |
|---|---|---|
| 条件 | 任意 v ≠ 0，v^T A v ≥ 0 | 任意 v ≠ 0，v^T A v > 0 |
| 允许等于 0 吗 | 允许 | 不允许 |
| 特征值 | 全部 ≥ 0 | 全部 > 0 |
| 几何含义 | 可能某个方向压扁成线 | 所有方向都有散布 |

### 为什么协方差矩阵是半正定（不一定是正定）？

v^T Σ v = 加权和 v^T x 的方差。方差 ≥ 0，所以是半正定。

但如果某个方向上的方差恰好 = 0（比如某个变量是常数不变化），那这个方向的特征值 = 0，矩阵就是半正定而非正定。

### 直观理解

拿置信椭圆来说：

- **正定** → 椭圆有面积（两个轴长都 > 0）
- **半正定但非正定** → 椭圆压成一条线（某个轴长 = 0），说明某个变量被完全确定

在卡尔曼滤波里，协方差矩阵理论上应该永远正定（每个变量都有不确定性），数值计算时偶尔会因为舍入误差变成半正定甚至奇异，这时就要做数值稳定处理。

## 性质 2 详细解释：迹非负

原文说：

> 由于对角元素非负，协方差矩阵的迹（对角元素之和）也非负：tr(Σ) = Σσii > 0

迹就是对角线全部加起来。因为每个对角线元素 = 某个变量的**方差**，方差 ≥ 0，所以和 ≥ 0。关键是**原文写的 > 0 并不严格**——如果所有变量方差都是 0（全是常数），迹可以 = 0。现实中不会发生，但数学上应该是 ≥ 0 不是 > 0。

卡尔曼滤波里：迹 = P 矩阵的对角线和 = 总误差。滤波收敛时迹会越来越小。

## 性质 4 详细解释：半正定

原文说：

> 如果对于任何向量 v ≠ 0，都有 v^T A v ≥ 0，则矩阵 A 称为半正定矩阵。A 的特征值均为非负。

**为什么协方差矩阵满足这个？**

取任意权重向量 v，构造一个新随机变量 y = v^T x = v_1 x_1 + v_2 x_2 + ... + v_n x_n。y 是一个**加权和**（线性组合），它也有方差：

\[
VAR(y) = VAR(v^T x) = v^T \Sigma v
\]

方差不可能为负 → v^T Σ v ≥ 0 → Σ 是半正定。

**为什么特征值都 ≥ 0？**

如果取 v 为特征向量，则 Σ v = λ v，代入：

\[
v^T \Sigma v = v^T (\lambda v) = \lambda (v^T v) = \lambda \|v\|^2 \geq 0
\]

因为 \(\|v\|^2 > 0\)，所以 \(\lambda \geq 0\)。特征值全非负。

**半正定和正定的区别在卡尔曼里：**

- 正定：全部特征值 > 0 → 所有方向都有不确定性 → 椭圆有面积
- 半正定：有特征值 = 0 → 某个方向被完全确定 → 椭圆压成线

## 半正定的本质含义

### 它是"非负"的矩阵版本

| 概念 | 一维（标量） | 多维（矩阵） |
|---|---|---|
| 非负 | x ≥ 0 | **半正定** |
| 正数 | x > 0 | **正定** |

一维说方差 ≥ 0，谁都懂。多维说协方差矩阵"合法"，不能直接说 Σ ≥ 0，需要一套规则——就是半正定。

### 这个乘法是怎么保证非负的？

核心问题：为什么偏偏是 \(v^T A v \geq 0\) 这个形式？

**从一维看起：**

一维时，矩阵 A 退化为一个数 a，向量 v 退化为一个数 v。那么：

\[
v^T A v = v \cdot a \cdot v = a v^2
\]

要求对任意 v ≠ 0 都有 a v² ≥ 0 → 因为 v² > 0，所以 a ≥ 0。

所以一维时，"v^T A v ≥ 0 对任意 v" 等价于"a ≥ 0"。**这个定义在一维退化回"数 ≥ 0"，是自洽的。**

**二维展开看看：**

\[
v = \begin{bmatrix} v_1 \\ v_2 \end{bmatrix}, \quad
A = \begin{bmatrix} a & b \\ c & d \end{bmatrix}
\]

\[
v^T A v = a v_1^2 + (b+c) v_1 v_2 + d v_2^2
\]

要求这个式子在**所有 v₁, v₂ 的组合下都 ≥ 0**。这不是自动成立的——对随便写的 a,b,c,d，总可以找到某个 (v₁, v₂) 让结果 < 0。

**所以"半正定"的定义就是在说：你找不到任何一个方向 v，能让这个二次型变成负数。**

**和方差的关系：**

\(v^T \Sigma v\) 算的是"按 v 加权后的新变量 y = v^T x 的方差"：

\[
VAR(y) = VAR(v_1 x_1 + v_2 x_2 + ... + v_n x_n) = v^T \Sigma v
\]

要求这个 ≥ 0 对全部 v 成立 = **无论怎么组合这些随机变量，组合后的方差都不会为负**。这就是非负的矩阵版本。

### 半正定 = 平方和

半正定矩阵可以写成 \(\Sigma = A^T A\)（对某个矩阵 A）。那么：

\[
v^T \Sigma v = v^T (A^T A) v = (A v)^T (A v) = \|A v\|^2 \geq 0
\]

平方和不可能为负。所以半正定本质上是说：**任何方向上的方差都是一个平方和，不可能为负。**

### 为什么必须要有这个性质

**1. 合法性检查**

随便写一个 2×2 矩阵，比如：

\[
\Sigma = \begin{bmatrix} 1 & 2 \\ 2 & 1 \end{bmatrix}
\]

算一下特征值：λ₁ = 3, λ₂ = -1。有负特征值 → 不是半正定 → **这个矩阵不能是协方差矩阵**，它代表一个现实中不存在的概率分布。

半正定就是协方差矩阵的**身份证**，用来判断一个矩阵是不是合法的协方差矩阵。

**2. 避免物理上不可能的结果**

违反半正定 → 某个方向上出现负方差 → 意味着置信椭圆某个轴长是虚数 → 荒谬。

**3. 卡尔曼滤波的数值保护**

实际计算时，由于舍入误差，P 矩阵可能慢慢变成非正定（出现微小的负特征值）。这会导致：

- 卡尔曼增益算错
- 置信椭圆画不出来（√负数）
- 滤波器发散

所以工程实现中会加保护：每次更新后检查特征值，把负的裁成 0 或一个很小的正数。

**一句话：半正定保证了你面对的是一个真实的、物理上可能的概率分布，而不是数学矛盾的东西。**
