# 二维卡尔曼滤波协方差传播推导

## 一、基础概念

### 方差 Var
一个变量自己有多不确定。

```
Var(T) = E[(T - E[T])²]
       = 平均的 (T 偏离均值的程度)²
```

比如温度 50°C，不确定度 ±2°C → Var(T) = 4。

### 协方差 Cov
两个变量一起变化的趋势。

```
Cov(T, r) = E[(T - E[T]) × (r - E[r])]
```

- T 偏大时 r 也偏大 → 乘积为正 → Cov > 0
- T 偏大时 r 反而偏小 → 乘积为负 → Cov < 0
- T 和 r 没关系 → 正负抵消平均为0 → Cov = 0

### 协方差矩阵

```
P = [ Var(T)      Cov(T, r) ]   =   [ p_T    p_cross ]
    [ Cov(r, T)   Var(r)    ]       [ p_cross  p_r   ]
```

对角线 = 各自方差，非对角线 = 协方差（对称，Cov(T,r) = Cov(r,T)）。

---

## 二、核心公式：线性变换下的协方差传播

如果：

```
y = A × x    ← y 是由 x 通过线性变换 A 得到的
```

那么概率论给出：

```
Cov(y) = A × Cov(x) × Aᵀ
```

这个公式可以直接使用，不需要每步推导。

---

## 三、套用到二维卡尔曼滤波的状态外插

### 状态外插方程

```
T_pred = T_est + Δt × r_est
r_pred = r_est
```

写成矩阵形式：

```
[T_pred]   =   [1  Δt] × [T_est]
[r_pred]       [0  1 ]   [r_est]
```

所以线性变换矩阵 A 为：

```
A = [1  Δt]
    [0  1 ]
```

已知上一轮的协方差矩阵 P_est：

```
P_est = [ p_T_est    p_cross_est ]
        [ p_cross_est  p_r_est   ]
```

根据公式 `P_pred = A × P_est × Aᵀ`，一步一步乘开。

---

## 四、矩阵乘法展开

### 第1步：A × P_est

```
A × P_est = [1  Δt] × [ p_T_est    p_cross_est ]
            [0  1 ]   [ p_cross_est  p_r_est   ]
```

行 × 列：

| 位置 | 计算 | 结果 |
|------|------|------|
| 第1行第1列 | 1×p_T_est + Δt×p_cross_est | p_T_est + Δt·p_cross_est |
| 第1行第2列 | 1×p_cross_est + Δt×p_r_est | p_cross_est + Δt·p_r_est |
| 第2行第1列 | 0×p_T_est + 1×p_cross_est | p_cross_est |
| 第2行第2列 | 0×p_cross_est + 1×p_r_est | p_r_est |

所以：

```
A × P_est = [ p_T_est + Δt·p_cross_est   p_cross_est + Δt·p_r_est ]
            [ p_cross_est                 p_r_est                   ]
```

---

### 第2步：(A × P_est) × Aᵀ

```
Aᵀ = [1  0 ]
     [Δt 1 ]
```

```
P_pred = (A × P_est) × Aᵀ
       = [ p_T_est + Δt·p_cross_est   p_cross_est + Δt·p_r_est ] × [1  0 ]
         [ p_cross_est                 p_r_est                   ]   [Δt 1 ]
```

#### 左上角 p_T_pred

```
(p_T_est + Δt·p_cross_est)×1 + (p_cross_est + Δt·p_r_est)×Δt
= p_T_est + Δt·p_cross_est + Δt·p_cross_est + Δt²·p_r_est
= p_T_est + 2Δt·p_cross_est + Δt²·p_r_est
```

**这就是 p_T_pred 的公式（未加 q_T 时）。**

#### 右上角 p_cross_pred

```
(p_T_est + Δt·p_cross_est)×0 + (p_cross_est + Δt·p_r_est)×1
= p_cross_est + Δt·p_r_est
```

**这就是 p_cross_pred 的公式。**

#### 左下角（对称，结果相同）

```
p_cross_est × 1 + p_r_est × Δt
= p_cross_est + Δt·p_r_est
```

#### 右下角 p_r_pred

```
p_cross_est × 0 + p_r_est × 1
= p_r_est
```

**这就是 p_r_pred 的公式（未加 q_r 时）。**

---

### 第3步：加上过程噪声 Q

过程噪声矩阵 Q：

```
Q = [ q_T   0  ]
    [  0   q_r ]
```

加到结果的对角线上：

```
p_T_pred   = p_T_est + 2Δt·p_cross_est + Δt²·p_r_est + q_T
p_cross_pred = p_cross_est + Δt·p_r_est
p_r_pred   = p_r_est + q_r
```

---

## 五、物理含义理解

| 式子 | 含义 |
|------|------|
| p_T_pred | 温度不确定度 = 原来的 + 速率不确定通过 Δt² 传过来的 + 协方差贡献 + 随机扰动 |
| p_r_pred | 速率不确定度 = 原来的 + 随机扰动 |
| p_cross_pred | 温度-速率相关性 = 原来的 + 随时间积累的 |

协方差 Cov(T, r) 是关键 —— 它让**一个温度测量值可以同时修正温度和速率两个状态**。

如果不理解这个传播公式，只需记住：
> **卡尔曼滤波里协方差的传播，用的就是概率论中"线性变换下协方差怎么变"的标准公式 Cov(y) = A·Cov(x)·Aᵀ，没有任何人为约定的成分，全部是数学推导出来的。**
