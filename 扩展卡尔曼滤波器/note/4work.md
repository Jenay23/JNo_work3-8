## 实验一：模型对比 — CV vs CA vs CTRV

### 背景

当前实现使用 **CV（恒定速度）模型**，状态 8 维：`[x, y, z, yaw, vx, vy, vz, vyaw]`。

但装甲板在实际运动中并非匀速直线——机器人会加减速、转弯。以下模型对真实运动的描述能力不同：

| 模型 | 状态维数 | 假设 | 优点 | 缺点 |
|---|---|---|---|---|
| **CV** | 8 | 速度恒定 | 简单稳定 | 跟不上加减速/转弯 |
| **CA** | 12 | 加速度恒定 | 跟上加减速 | 维数高，参数多，转弯仍受限 |
| **CTRV** | 6~10 | 转弯率恒定 | 适合旋转运动 | 非线性强，需要雅可比 |

### 1.1 CV 模型（当前）

```
状态:  x = [x, y, z, yaw, vx, vy, vz, vyaw]^T
转移:  x(k+1) = x(k) + v(k) * dt   （各分量独立）
       v(k+1) = v(k)
矩阵:  F = [I(4x4), dt*I(4x4); 0, I(4x4)]
```

### 1.2 实现 CA 模型

**状态向量**（12 维）：
```
x = [x, y, z, yaw, vx, vy, vz, vyaw, ax, ay, az, ayaw]^T
```

**状态转移矩阵 F**（12x12）：
```
F = [I  dt*I  0.5*dt²*I
     0   I     dt*I
     0   0     I     ]
```

每个维度独立，可块对角构造。

**过程噪声 Q**（12x12）：
- 位置 Q_pos：不变（0.002, 0.002, 0.0001, 0.0002）
- 速度 Q_vel：不变（0.005, 0.005, 0.005, 0.00001）
- 加速度 Q_acc：新增，通常远大于 Q_vel，建议 `{0.05, 0.05, 0.01, 0.001}`

**观测矩阵 H**（4x12）：与 CV 相同，只观测位置。

### 1.3 实现 CTRV 模型

**CTRV = Constant Turn Rate and Velocity（恒定转弯率与速度模型）**

它假设目标在相邻两帧之间的运动满足：
- **速率 v**（标量，不是 vx/vy 分量）保持不变
- **转弯率 ω (vyaw)** 保持不变

因此运动轨迹是**圆弧**（当 ω=0 时为直线），而不是 CV 模型假设的**直线**。

#### 与 CV 的关键区别

| | CV 模型 | CTRV 模型 |
|---|---|---|
| 运动轨迹 | 直线 | **圆弧** |
| 速度表示 | `[vx, vy]` 两个分量 | `v` 一个标量速率 |
| 状态转移 | `F * x`（线性） | `f(x)`（**非线性**，含 sin/cos） |
| 转弯描述 | 无法描述 | `vyaw` 自然描述转弯 |

#### 为什么 CTRV 更适合 RoboMaster 场景

机器人运动特点是**转弯 + 前进**：
- CV 模型认为目标走**折线**（每帧速度方向突变），跟不上旋转目标
- CTRV 模型认为目标走**圆弧**，vyaw 自然描述旋转，预测更准

代价是状态转移函数 f(x) 非线性，需要在 EKF 中手动推导**雅可比矩阵** F_k = ∂f/∂x，无法像 CV 那样直接用 F 矩阵相乘——这正是 EKF 中 "E"（Extended）的核心练习。

**状态向量**（6 维）：
```
x = [x, y, z, yaw, v, vyaw]^T
```
其中 `v` 是标量速率（不是 vx/vy 分量），`vyaw` 是偏航角速度。

**状态转移函数 f(x) —— 非线性**：
```
当 vyaw ≈ 0 时（近似直线运动）：
  x(k+1) = x(k) + v * cos(yaw) * dt
  y(k+1) = y(k) + v * sin(yaw) * dt

当 vyaw ≠ 0 时（转弯运动）：
  x(k+1) = x(k) + v/vyaw * (sin(yaw + vyaw*dt) - sin(yaw))
  y(k+1) = y(k) + v/vyaw * (-cos(yaw + vyaw*dt) + cos(yaw))

z(k+1)     = z(k) + vz*dt        （z 独立线性）
yaw(k+1)   = yaw(k) + vyaw*dt
v(k+1)     = v(k)
vyaw(k+1)  = vyaw(k) + ayaw*dt   （可加角加速度噪声）
```

**雅可比矩阵 F_k = ∂f/∂x** —— 需要手动推导：
```
F_k = [∂f_x/∂x  ∂f_x/∂y  ...  ∂f_x/∂vyaw
       ...                         ...      ]   (6x6)
```

关键偏导（以 vyaw ≠ 0 为例）：
```
∂f_x/∂yaw = v/vyaw * (cos(yaw+vyaw*dt) - cos(yaw))
∂f_x/∂v   = 1/vyaw * (sin(yaw+vyaw*dt) - sin(yaw))
∂f_x/∂vyaw = -v/vyaw² * (sin(yaw+vyaw*dt) - sin(yaw))
           + v/vyaw * cos(yaw+vyaw*dt) * dt
```

**观测矩阵 H**：与 CV 相同 `[I(4x4), 0(4x2)]`。

### 1.4 对比评估指标

| 指标 | 计算方式 | 说明 |
|---|---|---|
| **RMSE** | `sqrt(mean((filtered - raw)²))` | 滤波曲线与原始数据的差异 |
| **滞后帧数** | 原始和滤波曲线的互相关峰值偏移 | 滤波延迟多大 |
| **计算耗时** | 总帧数 / 总耗时 | CA 12维比 CV 8维慢多少 |

## 实验二：残差白噪声检验

> 残差 = z - H * x_pred。理论上，如果模型正确，残差应为**均值为 0 的白噪声**。

### 2.1 残差计算

在每个 EKF 更新步前记录残差：

```cpp
// 在 update 之前计算
Eigen::VectorXd residual = z - H * ekf.x;  // 或使用 z_subtract
```

输出残差序列，与滤波结果一起写到 CSV。

### 2.2 检验指标

| 检验 | 公式 | 合格标准 |
|---|---|---|
| **均值** | `mean(residual)` | ≈ 0 |
| **标准差** | `std(residual)` | 应与 sqrt(R) 接近 |
| **自相关（滞后1步）** | `corr(residual[1:], residual[:-1])` | ≈ 0 |
| **正态性** | 直方图 / QQ-plot | 接近正态分布 |

如果残差均值显著 ≠ 0 → **模型有偏，存在系统误差**。
如果残差自相关显著 → **模型动态不够，未捕捉全部运动模式**。

### 2.3 残差对比实验

对 CV、CA、CTRV 三个模型分别：

1. 绘制残差时间序列图
2. 绘制残差直方图（叠加 N(0, R) 理论曲线）
3. 计算自相关系数

#### 预期结果

| 模型 | 残差均值 | 残差自相关 | 说明 |
|---|---|---|---|
| CV | 非零（有偏） | 高 | 跟不上加减速 |
| CA | 接近 0 | 中低 | 加速度捕获了部分运动 |
| CTRV | 接近 0 | 低 | 最适合转弯场景 |

## 总结

通过实验一和二，你将直观理解：

1. **模型越复杂 ≠ 越好**：CA 虽然能跟上加速度，但多了 4 个 Q 参数要调，调不好比 CV 更差
2. **残差是模型质量的晴雨表**：残差序列的统计特性直接告诉你模型哪里不对
3. **雅可比推导是关键难点**：CTRV 的非线性推导让你真正理解 "Extended" 的含义
